# URL 參數解析工具

## 目的
這個工具用於解析 URL 的查詢參數（query string），可將參數逐筆列出，包含：
- **Key（參數名稱）**
- **解碼值（URL decode 後）**
- **原始值（未解碼的片段）**
- 支援 **重複 key**（例如 `tag=a&tag=b` 會顯示兩筆）

---

## 你可以輸入什麼
在輸入框中貼上以下任一格式皆可：

1. **完整網址**
   - 範例：`https://example.com/path?name=Bob&age=18`

2. **只貼查詢字串**
   - 例 1：`?name=Bob&age=18`
   - 例 2：`name=Bob&age=18`

3. **自帶 fragment 的網址片段**
   - 工具會自動忽略 `#` 之後的內容  
   - 例如：`https://x.com/?a=1#section` 只解析 `a=1`

---

## 解析規則（重點）
- 工具會擷取輸入中**第一個 `?`** 之後的內容作為查詢字串。
- 以 `&` 拆分每個參數片段。
- 每個片段：
  - 若包含 `=`：視為 `key=value`
  - 若不包含 `=`：視為 `key` 且 `value` 為空字串 `""`
- 解碼使用類似 `decodeURIComponent` 的概念，並把 `+` 視為空白（`%20`）。

---

## 操作說明
- **解析（解析按鈕）**
  - 解析輸入內容並更新下方結果區塊。
- **清除（清除按鈕）**
  - 清空輸入與所有輸出結果。
- **複製結果(JSON)**
  - 將目前解析結果以 JSON 格式複製到剪貼簿。
  - 若瀏覽器不允許剪貼簿操作，會嘗試使用後備方式複製。

---

## 輸出內容
解析結果分為幾部分：

1. **解析結果摘要**
   - 顯示解析到的參數筆數。

2. **表格**
   - 每筆參數一列：
     - Key
     - 解碼值
     - 原始值

3. **JSON（便於後續使用）**
   - 格式包含：
     - `query`: 解析使用的原始查詢字串
     - `params`: 參數陣列（每筆含 `key`, `value`, `rawKey`, `rawValue`）

---

## 範例
### 輸入
`?name=Bob&tag=a&tag=b&empty=&noeq`

### 會得到
- `name`：value = `Bob`
- `tag`：兩筆（`a` 與 `b`）
- `empty`：value = ``
- `noeq`：value = ``（因為沒有 `=`）

---

## 注意事項
- 若輸入含不合法的 escape 序列，解碼可能回退為原始字串（避免整體解析失敗）。
- 工具僅解析查詢字串，不會處理 path 或其他 URL 結構。
