# URL 編碼 / 解碼

將文字進行 URL 編碼或解碼，適用於：
- 把特殊字元轉成可安全放進 URL 的形式（例如空白、中文、`%`、`?` 等）
- 針對已編碼字串進行解回原本文字

---

## 功能

- **編碼**：使用 `encodeURIComponent` 對輸入內容做完整 URL 編碼
- **解碼**：使用 `decodeURIComponent`（若失敗會再嘗試 `decodeURI`）
- **清除**：清空輸入與輸出
- **複製輸出**：將結果複製到剪貼簿
- 顯示狀態提示（成功 / 失敗）

---

## 行為說明

- 解碼時會先把輸入中的 **`+` 轉成空格**  
  （符合常見的 `application/x-www-form-urlencoded` 行為）

---

## 快捷鍵

- **Ctrl/Cmd + E**：編碼
- **Ctrl/Cmd + D**：解碼
- **Ctrl/Cmd + L**：清除
- **Ctrl/Cmd + Shift + C**：複製輸出

---

## 使用方式

1. 在左側輸入框貼上文字或已編碼字串
2. 按下：
   - **編碼**：得到 URL 編碼結果
   - **解碼**：得到原始文字結果
3. 必要時可使用 **複製輸出** 取用結果

---

## 可能的錯誤

- 若解碼輸入包含不完整或錯誤的百分比編碼（例如 `%E4%` 之類），會顯示解碼失敗提示並清空輸出。
