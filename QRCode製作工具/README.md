# QRCode 產生器

一個可高度自訂樣式的 QRCode 產生工具，提供直覺化的操作介面，讓使用者能快速建立符合需求的 QRCode，無論是用於分享連結、展示資訊或設計用途，都能輕鬆完成。

---

## 介紹

此工具專注於「簡單但不簡陋」，在保有輕量與快速的前提下，提供多種實用的自訂功能。使用者可以自由調整 QRCode 的外觀與內容，打造更具個人風格或品牌識別的 QRCode。

透過即時設定與生成，整個流程簡潔流暢，不需要額外安裝或複雜操作，即可完成從輸入到輸出的完整體驗。

---

## 功能特色

- 支援輸入任意文字或網址內容，快速生成 QRCode  
- 可自訂前景顏色，打造不同風格的 QRCode 外觀  
- 可設定背景顏色，提升辨識度或符合設計需求  
- 支援背景漸層效果（水平 / 垂直），讓畫面更有層次  
- 可上傳圖片作為中央 Logo，強化識別性  
- 提供多種馬眼樣式（方形、圓點、圓角）  
- 可調整錯誤容忍率，平衡美觀與掃描穩定性  
- 支援自訂輸出尺寸，適用於不同使用情境  
- 一鍵下載 QRCode 圖片，方便保存與分享  

---

## 使用技術

- HTML5 建立結構與基本介面  
- CSS3 負責樣式設計與版面配置  
- 原生 JavaScript 處理邏輯與互動  
- qr-code-styling 用於生成可自訂樣式的 QRCode  
- html2canvas 用於將畫面轉換為圖片並下載  

---

## 設計理念

本工具的核心理念是讓 QRCode 不再只是單純的黑白方塊，而是一個可以被設計與個性化的視覺元素。

透過提供顏色、樣式與圖像的調整能力，讓使用者可以依照不同需求，產出更具辨識度與美感的 QRCode。同時也兼顧實用性，確保在各種設定下仍具備良好的掃描成功率。

---

## 功能說明

在內容輸入方面，使用者可以輸入網址、文字或任何資訊，系統會即時轉換為 QRCode。  
顏色設定允許調整 QRCode 的前景與背景，使其更符合視覺設計需求。  
背景樣式除了單色之外，也支援漸層效果，讓畫面更加豐富。  

若需要品牌識別或個人風格，也可以上傳圖片作為中央 Logo，嵌入 QRCode 中央位置。  
馬眼樣式提供不同外觀選擇，讓整體視覺更具變化性。  
錯誤容忍率則可調整掃描穩定性，在加入 Logo 或複雜樣式時尤其重要。  

完成設定後，可以直接將 QRCode 匯出為圖片，方便用於各種用途，例如分享、列印或設計素材。
