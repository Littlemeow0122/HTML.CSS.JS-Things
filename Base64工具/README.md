# Base64 工具（文字 / 圖片 / 音樂 / 影片 / 任意檔案）

一個可在瀏覽器中進行的 Base64 工具，支援：

- **編碼**
  - 文字 → Base64（UTF-8）
  - 檔案（圖片 / 音樂 / 影片 / 任意二進位）→ Base64
- **解碼**
  - Base64 → 文字（若內容看起來像文字）
  - Base64 → 二進位（並嘗試顯示預覽；若非文字則輸出 data URL）
- **Base64 版本選擇**
  - 經典 base64 (RFC 4648)：不插入換行
  - Apple 版本：每 **76 字元**插入換行（MIME-style）
- **輸出可選**
  - 編碼檔案時可選擇是否包含 `data:...;base64,` 頭
- **操作**
  - 複製結果
  - 下載結果

---

## 使用流程（操作概念）

1. 選擇：
   - 動作：**編碼** 或 **解碼**
   - 來源：**文字** 或 **檔案**
   - 版本：**經典** 或 **Apple**
2. 輸入內容或選擇檔案
3. 點擊 **執行**
4. 使用 **複製結果** / **下載**

---

## 編碼規則

### 文字編碼
- 將文字以 **UTF-8 bytes** 形式轉換後再做 Base64。

### 檔案編碼
- 讀取檔案 bytes 後轉 Base64。
- 若啟用「包含 data URL 頭」，輸出格式為：
  - `data:<file.type 或 application/octet-stream>;base64,<base64>`

### Apple 版本格式
- Base64 內容會每 **76 字元**插入換行。

---

## 解碼規則

1. 若輸入符合 data URL 格式（`data:<mime>;base64,<...>`）：
   - 會自動移除前綴並保留 mime
2. 解碼後會嘗試將 bytes 判斷是否為「文字」
   - 若像文字：直接輸出文字到結果框
   - 若不像文字：輸出成 data URL（方便預覽/下載）

---

## 複製與下載

### 複製結果
- 會把「結果」區內容寫入剪貼簿。

### 下載結果
- 解碼模式下若結果包含 data URL：
  - 會解析 data URL 的 mime 與 base64，嘗試以原始二進位方式下載
- 其他情況：
  - 會以文字檔下載目前結果內容（`base64-result.txt`）

---

## 預覽支援

- 若內容為圖片/音樂/影片，會在預覽區顯示媒體。
- 若內容不適合預覽，預覽區會隱藏。

---

## 注意事項

- 解碼後是否「視為文字」使用啟發式判斷，可能會因資料內容而有所差異。
- Base64 的版本選擇（經典/Apple）主要影響換行格式，不影響還原出的二進位本質。
