# JSON 格式化 / 壓縮工具

一個可在瀏覽器中進行的 JSON 處理工具，支援：

- **格式化（Pretty Print）**
  - 將壓縮的 JSON 轉換為易讀的格式化版本
- **壓縮（Minify）**
  - 移除 JSON 中的所有空白字符，生成最小化的版本
- **即時驗證**
  - 自動檢查輸入的 JSON 是否有效
- **統計資訊**
  - 顯示輸入/輸出長度
  - 計算壓縮率
- **操作功能**
  - 複製輸出結果
  - 清空輸入
  - 生成後自動複製選項

---

## 使用流程（操作概念）

1. 在輸入框中貼上或輸入 JSON 內容
2. 選擇動作：
   - **格式化**：將 JSON 美化為易讀格式
   - **壓縮**：移除所有空白，生成最小化版本
3. 查看輸出結果
4. 使用 **複製** 按鈕複製結果，或勾選「生成後自動複製」

---

## 功能說明

### 即時驗證
- 預設啟用，輸入時自動檢查 JSON 語法
- 無效 JSON 會顯示錯誤訊息

### 統計資訊
- **長度**：顯示輸入和輸出的字符數
- **壓縮率**：輸出長度相對於輸入長度的百分比
  - 格式化時通常 > 100%
  - 壓縮時通常 < 100%

### 錯誤處理
- 無效 JSON 會阻止格式化和壓縮操作
- 錯誤訊息會顯示在輸入面板下方

---

## 技術細節

- 基於原生 `JSON.parse()` 和 `JSON.stringify()` 實現
- 格式化時使用 2 個空格縮進
- 完全在瀏覽器中運行，無需伺服器端處理
- 支援所有有效的 JSON 結構

---

## 相容性

- 支援所有現代瀏覽器
- 需要 JavaScript 啟用
